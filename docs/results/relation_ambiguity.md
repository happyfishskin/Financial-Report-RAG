# 關係事實直查之候選歧義率

由 `measure_relation_ambiguity.py` 產生：自十一份凍結結果檔取出關係軌題目，
連同已凍結的 `router_decision` 重放 `_gkg_pattern_direct_answer()`，以 `sys.settrace`
讀取候選挑列點的候選列數。**零 LLM 呼叫、零重跑推論、未修改 `rag_test_system_v14.py`**。

## 結論

- 關係軌題目 **360** 題，其中 **289** 題抵達候選挑列點
- 候選不唯一且系統靜默任選（`iloc[-1]`）：**17** 題
- **候選歧義率 = 5.88%**；**held-out 四組 = 0.0%**

對照：數值事實直查在候選不唯一時**立即拒答**（`_REFUSE_ON_AMBIGUOUS`），其候選歧義率為 0.0%。
關係事實直查**無對應拒答機制**——六個 L0 樣板在候選不唯一時取 `iloc[-1]`（「最後揭露列優先」）
或全列並列。本表量測該分支的實際觸發率。

## 限制

- 本量測僅涵蓋抵達六個候選挑列點的題目（289/360）。其餘 71 題或由風險標記樣板
  （標籤聯集，非挑列）答出、或在挑列前即回傳、或未被 L0 攔下而降級，不在統計內。
- 候選數取自挑列當下的 DataFrame 列數；若同一題在多個樣板都挑過列，取最大者。
- 「全列並列」不計為歧義：該分支輸出全部候選、未丟失資訊，且僅於題幹明示
  「請全部列出」時觸發（口語 100 之 customer_colloquial_094/095）。
