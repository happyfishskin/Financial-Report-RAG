# 可維護設定

這個目錄放置日後可能需要調整的 JSON 設定，避免將領域資料寫死在 Python 程式中。

- `company_aliases.json`：市場簡稱 → 資料夾/財報使用的申報全名。
- `system_config.json`：資料路徑、模型、圖譜來源、科目與比率本體論、路由關鍵字。

`financial_ontology` 目前覆蓋 11 個標準科目、172 個對應詞；`ratio_ontology`
覆蓋 7 種比率、54 個對應詞。程式對原句採「最長同義詞命中」，因此像
「本業獲利」會優先於較短的「獲利」。新增對應詞時必須保持會計意義相同；
例如不可將「應付帳款」放進「負債總計」，否則會把子科目誤當總額。

7 種比率為：毛利率、營業利益率、淨利率、負債比率、研發費用率、
現金占資產比率、現金對總負債比率。所有公式目前皆輸出百分比，分子與分母必須是
`financial_ontology` 能穩定查到、且期間口徑一致的原始科目。

新增別名時，在 `company_aliases.json` 增加一組鍵值：

```json
{
  "台積電": "台灣積體電路製造"
}
```

左邊是使用者可能輸入的簡稱，右邊必須與資料中的公司全名完全一致。修改後需重新啟動程式，設定會在匯入模組時載入。JSON 不支援註解，且最後一筆資料後面不能放逗號。
